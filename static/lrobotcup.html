        01 / RESEARCH

        调研结论：这个行业到底要什么人

        2026 年的具身智能不是「学会一个框架」就能进，而是要打通一条完整链路。下面四条是本轮调研最值得先记住的结论。

        01

        闭环，而不是单点

        招聘 JD 里最高频的词是 VLA、世界模型、模仿学习、强化学习、Sim2Real、多模态融合。企业要的是能把「数据 → 训练 → 部署 → 真机」跑通的人，不只是会调某个模型。

        事实 · 2026 年招聘页
        02

        最缺的是「跨栈」的人

        人才报告原话是「懂算法的不懂本体、懂机械的不懂大模型」。有招聘方明确偏好「把机械臂逆解推导清楚」的候选人，而不是只会用大模型的人。

        事实 + 建议
        03

        入门不一定要买硬件

        Hugging Face Robotics Course 明确「无需硬件」：纯仿真 + 公开数据集就能跑完第一轮。若要上真机，SO-101 级机械臂约 100–500 美元（2025-04 报价，含组装/运费差异）。

        易变 · 价格请复核
        04

        先读一篇教程，再读论文

        Robot Learning: A Tutorial（HF × 牛津，arXiv:2510.12403，2025-10）从经典机器人学一路讲到通用语言条件策略，附 LeRobot 可运行示例，是本轮最推荐的第一篇通读材料。

        事实 · 已直连验证

        六条岗位线，按能力对照

        点开看职责、硬性能力与招聘关键词，选一条作为 3–6 个月的主攻方向。

        关于数字的提醒

        招聘指数、薪资、数据集规模、模型参数量都来自媒体或二手报告，已发现同一数据集规模存在 4 种口径。本页涉及数字时统一标注来源与时间；求职与选型请回到论文、官方仓库与官方发布页复核。

        02 / ROADMAP

        三阶段学习路线

        每阶段都有可勾选的任务与明确的验收标准。登录后勾选会同步到社区账号（跨设备不丢，还会触发成就与等级）；游客先存在本机，登录后自动合并。

        跑通最小闭环

        建立全局认知，在纯仿真 + 公开数据集上跑完「数据 → 训练 → 评估」

        要学

        L0 数学与 Python / Linux / Git / PyTorch；L1 坐标变换与正逆运动学概念、ROS2 基础；L2 CNN / Transformer 概念；读 Robot Learning: A Tutorial 前几章。

        验收标准

        能解释「观测 / 状态 / 动作 / action chunk」；能独立复现一次训练并说清超参作用；能讲明 ROS2 的 topic / service / action 区别；产出 1 个带 README 的 Git 仓库。

        动手清单

        避坑：这个阶段不要买硬件、不要追新论文、不要同时开三个方向。

        按岗位定向

        选定一条赛道，完成 2–3 个有含金量的经典复现

        要学

        L3 全量（PPO / SAC / BC / DAgger / 离线 RL）；ACT、Diffusion Policy、OpenVLA 架构；L1 进阶（逆解、轨迹规划、阻抗控制、手眼标定、点云）；深入一种仿真器（MuJoCo 或 Isaac Sim）。

        验收标准

        能在同一任务上对比 BC / ACT / Diffusion Policy 成功率并解释差异；能把策略部署到仿真机械臂连续跑 20 次并统计成功率；开始写复现笔记。

        动手清单

        对应 JD 加分项：「复现过 OpenVLA、RDT」「有 ACT / 扩散策略 / VLA / 真机 RL 经验」。

        Sim2Real 与作品集

        形成「采集 → 训练 → 部署 → 真机验证」的完整作品集

        要学

        L4 全部（VLA 家族、世界模型、OXE / DROID / LeRobot 数据管线）；L5 域随机化、系统辨识、推理加速、多模态融合、动作 chunk 与高低频双系统。

        验收标准

        有一个端到端项目能从遥操作采集跑到真机自主执行，报告里带基线对比、失败分析、随机种子与版本记录；能解释 sim2real gap 的三类来源。

        动手清单

        面试信号：「能讲清楚自己关注的论文和原因」——这是 JD 原文。

        三条硬件路径，别反过来走

        推荐顺序：先零硬件跑通 → 加 GPU 做规模 → 最后上真机补物理直觉。「先买臂再学代码」是社区复盘里最常见的浪费。

        零硬件

        HF Robotics Course → LeRobot Push-T / LIBERO → 社区数据集清洗 → SB3 → 读 OpenVLA / π0 代码 → Colab 上 LoRA 微调。

        做不到：真机接触、力控、标定、延迟与传感器噪声经验；简历需诚实标注「仿真」。
        ▣

        消费级 GPU，无机械臂

        本地跑 Isaac Lab / MuJoCo、微调 7B 以下模型、合成数据与域随机化实验；可参加提供算力的仿真赛事。

        性价比最高的自学配置；仍然缺最后的 real 环节。

          03 / STACK

          L0 → L5 知识栈

          L0–L1 决定「能不能和机器人对话」，L2–L3 决定「能不能让机器人学」，L4–L5 决定「能不能做出一线水平的工作」。每层都给了验收标准。

          L0数学与编程基础全岗位底座

          线性代数（矩阵 / 特征值 / SVD / 李群李代数初步）、概率统计、多元微积分、最优化；Python（NumPy / Pandas）、C++（工程与嵌入式岗必备）、Linux / shell、Git、Docker、PyTorch。

          验收：手写 NumPy 实现坐标变换与最小二乘；独立配好 conda + PyTorch + CUDA 并跑通开源仓库；提一个有效 PR。

          L1机器人学基础最容易被跳过的一层

          坐标变换、旋转表示（矩阵 / 欧拉角 / 四元数 / 指数坐标）、螺旋理论、DH 参数、URDF；正逆运动学、雅可比、动力学；轨迹生成、PID / 阻抗 / 导纳控制、MPC、WBC；相机模型、RGB-D 点云、IMU、力传感器、手眼标定、PnP、TF 树；ROS2 的 topic / service / action、TF2、MoveIt2、ros2_control、Nav2、Gazebo。

          验收：手推六轴机械臂逆解；用 ROS2 + MoveIt2 让仿真臂完成一次抓取；能把真实物体输出成「机器人坐标系下的位置 + 朝向」。

          版本提示：ROS 2 官方推荐 LTS 为 Lyrical Luth，Jazzy 支持至 2029-05，Kilted 将于 2026-11-30 EOL（docs.ros.org，2026-11-05 查）。新项目避开即将 EOL 的版本。

          L2机器学习 / 深度学习模型语言

          反向传播与训练闭环、CNN / ViT / Transformer / 注意力、CLIP 类视觉语言对齐、多模态融合；扩散模型、流匹配、VAE / CVAE、动作 chunk；混合精度、FSDP / Deepspeed、LoRA、量化 / ONNX / TensorRT、异步推理。

          验收：从零用 PyTorch 训一个小模型并画损失曲线；读懂 OpenVLA / π0 架构图，说清图像 token、语言 token、动作 token 各自怎么进网络。

          L3强化学习与模仿学习策略从哪来

          MDP、值函数、DQN、策略梯度、Actor-Critic；PPO / SAC、TD3、GAE、model-based RL、离线 RL；行为克隆 BC、DAgger、GAIL、ACT、Diffusion Policy、VQ-BeT；真机 RL 的安全与样本效率、HIL-SERL、奖励设计、动作分块、Sim2Real。工具：Stable-Baselines3、Gymnasium、RoboMimic、MuJoCo Playground。

          验收：用 SB3 训 PPO / SAC 并解释奖励曲线；在 RoboMimic 或 LeRobot 上跑通 BC → ACT → Diffusion Policy 并对比成功率。

          教程指出：简单 BC 有复合误差与演示多模态两大挑战；Diffusion Policy 仅需 50–150 条演示即可训练；HIL-SERL 真机 1–2 小时可掌握复杂操作任务。

          L4VLA / 世界模型 / 数据集2025–2026 前沿

          两条 VLA 路线：离散自回归（RT-2、OpenVLA 7B，动作当语言 token）与连续生成式（Octo、π0 流匹配、GR00T、SmolVLA）。趋势是层级化架构（高层语义子任务 + 底层连续动作）与潜在动作学习。世界模型建议先读一篇综述建立坐标系，不必追每篇新论文。

          数据集：Open X-Embodiment（跨本体预训练事实标准，规模口径从 16 万演示到 240 万轨迹不等，需注明口径）、DROID（7.6 万轨迹 / 564 场景）、BridgeData V2、ALOHA、LeRobot Hub、LIBERO / Meta-World。

          验收：能说清一条 VLA 的训练数据格式、动作表示与推理频率；能在 LeRobot Hub 上下载并可视化一个社区数据集。

          L5仿真与工程化能不能落地

          MuJoCo（接触丰富操作，CPU 可跑）、Isaac Sim / Isaac Lab（GPU 并行，需 RTX 且有严格版本配对）、Gazebo（ROS2 原生全系统仿真）、PyBullet、Habitat / SAPIEN / RLBench / RoboSuite。工程关键词：域随机化、系统辨识、数字孪生、动作 chunk、控制环延迟（50–200 ms 足以毁掉策略）、INT8/INT4 量化、TensorRT / ONNX、异步推理、真机安全（急停 / 限速 / 接触力约束）。

          验收：锁定版本 + 随机种子 + 依赖清单；升级前用一个已知场景做回归对比；能给出 sim / real 成功率差的三类来源解释。

          七个最容易踩的坑

          1. 只刷论文不碰系统：企业看的是你解决过什么问题，每读一篇论文配一个最小复现。
          2. 低估 Sim2Real gap：视觉 / 动力学 / 传感器噪声三类来源；别把仿真成功率当验收指标。
          3. 数据质量差：先固定采集 SOP（摄像头、视角、演示一致性），补 50 条针对性数据常比换架构有效。
          4. 算力与版本陷阱：避开 7B 全量训练，走 SmolVLA（450M）/ LoRA / 单卡；锁定版本与随机种子。
          5. 追新、贪多：仿真优先、先跑通再深究、单点深耕。资料请看清截止日期。
          6. 只学 AI 或只学机械：算法侧补坐标变换与控制频率，机械侧补 Transformer 与部署。
          7. 引用不实数字：同一数据集规模有 4 种口径，论文 / 榜单以 arXiv 与官方仓库为准。
