# 心映 · 动漫人格探索：结果页原型

直接在浏览器中打开 `index.html` 即可查看，无需安装依赖或启动 Django。文件内嵌 CSS、JavaScript 和角色图片，可在 file:// 下使用，下载档案也不依赖网络。

本目录只用于评审结果页的结构和视觉，尚未注册网站路由或接入真实测评服务。

- 首屏是一张可完整截图的分享卡：唯一角色立绘、姓名与作品、原创共鸣文案、MBTI 类型、四轴数据、双方六维图、答题原话及品牌署名。
- 六维图同时呈现测试者（绿色实线、圆点）和角色（暖棕虚线、方点），维度标签下按“测试者 / 角色”显示数字。全页只保留一张雷达图和一组四轴数据，不另设重复表格。
- 测试者雷达图和偏好轴由 `report.js` 中明确标识的虚构回答计算；角色曲线由明确标识的演示编辑标注映射，不是角色作答或官方人格数据。
- 轮廓接近指数为 `100 - mean(abs(user[i] - character[i]))`，不是人格概率；正式上线前角色逐维标注需要剧情证据和统一锚点。
- “你曾这样说”保留原话，未改写。底部关系解读不再重复引用同一句话。
- 按设计要求移除面向用户的原型、虚构示例、图片来源、共鸣文案来源、算法解释等说明。这些信息仍保留在本说明、源代码注释和素材来源文件中，数据性质没有改变。
- 原始作答默认不展示；仅在用户明确选择附上作答的下载或打印中添加，不混入默认分享卡。
- 类型、候选、访谈及角色匹配为预设演示，不能视作真实测评结果。
- 角色喜好反馈只改变本页显示，不上传、不持久化、不改变匹配。
- 保存按钮下载独立 HTML，可选是否附带原话或原始作答；导出移除脚本与操作控件。支持使用同一隐私选项打印 / 保存 PDF。
- 未生成海报、未接入账号、未新增收费、未修改现有导航。

## 设计方向

暂定名称：心映 · 动漫人格探索。品牌保留“心映”，副标题向动漫受众说明主题。

色彩：浅雾绿背景 `#f5f8f6`、白色阅读面 `#ffffff`、深青文字 `#223e3e`、森林绿重点 `#346a5e`、暖棕角色对照 `#9b704c`。角色立绘承担主视觉。中文宋体用于标题，微软雅黑/苹方用于正文。

### 视觉打磨

当前使用雾绿 `#eef3ee`、纸白 `#fcfdf9`、深松绿 `#263f36`、苔绿 `#396553` 与淡金棕 `#98724b`。保留角色图片和全部报告内容，以纸张材质、低对比窗光及植物线稿强化私人动画档案的感觉。

主视觉采用更宽的人物画面、细线拱形背景；标题使用疏朗宋体，MBTI 使用 Georgia，答题原话使用楷体。关键词改成轻下划线，雷达图加大、减轻网格并保持实线/虚线及圆点/方点区分。原话区增加独立引号和小幅倾斜的品牌署名。

审视方向时保留了夏目这一页的自然意象，装饰集中在角色背景和原话区；没有新增模块或反复展示内容。光影、纸张与植物均由 CSS / 内联 SVG 构建，官方角色立绘保持原样。

桌面分享卡左侧为角色立绘，右侧上方为人格与角色文案，下方并列六维图与 MBTI 四轴，卡底放原话。窄屏将图表区放在角色与文案区下方，仍保留两图并排。后续只展开生活模式、相似与不同、成长建议；不重复角色身份、图表和数据。打印时分享卡独占第一页。

## 编辑与构建

修改 `index.template.html`、`report.css`、`report.js` 后运行：

```powershell
python static/personality-preview/build_preview.py
```

脚本生成自包含 `index.html`。不要直接编辑生成文件。

角色立绘来自动画官方网站角色页，仅用于此原型的角色展示，源地址记录于 `assets/SOURCES.md`。

角色心理机制比较为示例解读，角色故事事实参考动画官网：
