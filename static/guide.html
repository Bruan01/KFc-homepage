从这里开始。

这里不是一张功能清单，而是一条可以边走边试的入站路线。先认识社区，再找到你的第一个动作。

这条路线没有标准答案。你可以跳着看，也可以先去做最想做的事。

↗

先记住一件事： KFlow 是一个把作品、讨论、学习和工具放在一起的社区。你不需要一次学会全部，只要找到下一步。

01
ARRIVE / 到达

先认识社区

从首页开始

你会看到一个围绕 vibecoding 作品展开的社区：有人展示刚做好的产品，有人分享方法，也有人在评论里帮忙补全思路。

你会看到什么

首页聚合最新作品、站内热榜和社区入口；论坛页则提供分类、搜索、主题详情和回复。

/→/forum
现在建议做什么

先打开几篇作品帖，看看大家如何描述问题、展示结果和留下项目链接。

浏览社区首页 ↗
◎社区首页最新作品、热榜和第一眼入口↗ ☷论坛全览分类、搜索、主题和回复↗
02
JOIN / 加入

建立你的身份

让社区认识你

浏览可以匿名开始，但登录之后，你才能发帖、回复、积累积分、保存个人资料并展示自己的作品。

登录与注册

使用熟悉的账号入口完成登录或创建账号，之后可以从顶部菜单回到个人中心。

去登录 / 注册 ↗
个人中心

管理资料、积分、下载和账户相关信息，是你自己的设置空间。

打开个人中心 ↗
个人主页

从论坛作者卡片进入某个用户主页，可以看到他的作品、贡献和勋章展示。

从论坛认识作者 ↗
03
LOOK AROUND / 探索

发现热门内容

找到值得看的东西

当你还不知道从哪里开始时，排行榜和统计页是很好的导航：它们告诉你最近什么项目被关注、谁在持续贡献。

01
排行榜

浏览全网项目、站内作品和创作者排行。点进项目卡片，还能查看它的详细信息。

打开排行榜 ↗
02
贡献统计

从社区活跃度、作品和贡献者维度理解这里正在发生什么。

查看贡献统计 ↗
04
LEARN / 学习

学习与查词

把看不懂的地方补上

教程适合顺着读，术语表适合随手查。你可以先从一个具体问题出发，再回到更系统的内容。

▤教程 · Vibecoding 开发者手册从需求、提示词到测试、发布和持续演进↗ Aa术语表遇到 Agent、RAG、Prompt 等概念时来这里查↗
TIP

不要把“看完所有内容”当成目标。带着一个具体问题读完一小节，再去论坛或工具里试一次，记得更牢。

05
MAKE / 创作

动手创作

把想法变成图像

显影是 KFlow 里的创作工具入口。你可以从模板开始，也可以把自己的想法写成提示词，再查看生成历史。

给新手的第一个动作选一个模板，改写一句描述。

先观察输入和结果之间的关系，熟悉生成、历史与下载的路径。

打开显影 ↗
CREATE从一句话开始template → prompt → image
06
GET / 获取

获取产品

找到可以使用的东西

产品站是 KFlow 自有产品的交付入口。这里重点看产品介绍、版本、平台、更新说明和安装方式，而不是只看一个下载按钮。

产品站

先浏览产品列表，按介绍判断它是否适合你的场景，再进入产品详情查看版本信息。

浏览产品站 ↗
产品详情

具体产品会有独立详情页，通常从产品卡片进入，查看安装、更新和下载信息。

/products→/product/<slug>
07
VALUE / 回到社区

积分与商店

贡献会留下痕迹

发帖、回复和参与社区会产生贡献与积分。积分不是必须追逐的任务，但它让你的参与有了可见的回馈。

+参与发帖、回复、互动
K积分查看规则与明细
↗兑换去 kflowstore 看看
KK 积分积分规则、明细和可用权益↗ □kflowstore兑换好物，也可以看看创作者货架↗
08
GROW / 成长

成长与成就

让持续参与被看见

成就和等级是社区里的两种反馈方式：一个记录你完成过什么，一个反映你长期贡献的积累。

✦成就勋章完成特定行为后获得，并可以展示在个人身份旁↗ 08等级体系查看等级和贡献成长的关系↗
09
KEEP GOING / 继续

服务与外部入口

需要时再来这里

当你想确认服务是否正常，或者想了解 KFlow 之外的独立产品时，可以从这两个入口继续。

✓服务状态查看 API 中转站和相关服务的实时状态；`/newapi` 是同一页面的别名↗ ◈Cardloom进入 KFlow 体系中的独立产品官网↗
