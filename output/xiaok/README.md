## 后续素材必须保持的外貌

- 银白色长卷发，带冷灰与淡紫灰阴影，轻盈分层刘海和两侧碎发；头顶一根弯曲呆毛。
- 柔和脸型、浅肤色、灰蓝色眼睛；睁开的眼睛中保留直立的白色大写 K 瞳孔标志。眨眼表情按原始设定表现，另一只睁开的眼睛保持 K。
- **正面观察者左侧**：黑色蝴蝶结，结上有小白 K；**正面观察者右侧**：黑色 K 形发夹。分别对应角色自身右侧和左侧。
- 不得用水平镜像改变朝向，否则发饰会换边、K 也会反转。需要不同朝向时应重新按参考图生成。
- 衣服、动作和表情可扩展；保持同系列线稿、银白发色和黑白灰蓝配色。
- 正式使用前按目标尺寸检查 K 瞳孔与发饰可辨识度。头像和很小的入口适合另外制作近景版本。
