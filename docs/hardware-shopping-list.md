### 建议买

| # | 东西 | 为什么 | 参考价 |

| 5 | 万用表 | 白屏时能立刻分清是供电、接地还是信号问题，新手最能省时间的一件 | ¥40 |

### 现在不用买

- 面包板 —— 开发板和屏幕都有排针，母对母线直接插，用不上

- 按键 —— 触摸屏已经能交互
- 外壳、铜柱螺丝 —— 等能显示真实数据之后再量尺寸
- SD 卡 —— 模块上的卡槽用不到

**路线 A 合计：约 ¥85–145（含万用表约 ¥125–185）**

## 下单前必须跟卖家确认的四件事

### 屏幕（2.8" TFT）

1. **驱动 IC 是 ILI9341 还是 ST7789？** —— 库的配置完全不同，买错点不亮
2. **触摸是电阻（XPT2046）还是电容（FT6236）？** —— 两者代码不通用
3. **排针焊好了吗？** —— 没焊的话还得买电烙铁
4. **要一份引脚定义图 / 2D 结构图** —— 接线和做外壳都用得上

话术：

> 麻烦确认三件事：驱动芯片是 ILI9341 还是 ST7789？触摸是电阻还是电容？排针是已经焊好的吗？另外能发一份引脚定义图吗？

### 开发板（ESP32-S3）

- 确认是 **N16R8**（16MB Flash + 8MB PSRAM），不是 N16R2
- 确认是 **44 脚**开发板，不是裸模组

## 收货后先做两件事

**1. 验线。** USB-C 线插上任一设备，终端跑：

```bash
ls /dev/cu.*
```

多出 `cu.usbmodem*` 或 `cu.wchusbserial*` 才是数据线，否则是充电线。

**2. 验板。** 不接屏幕，先烧一段打印：

```cpp
void setup() {
  Serial.begin(115200);
  Serial.printf("PSRAM: %d bytes\n", ESP.getPsramSize());
  Serial.printf("Flash: %d bytes\n", ESP.getFlashChipSize());
}
void loop() {}
```

PSRAM 应该接近 `8388608`，Flash 接近 `16777216`。数值不对直接退货。
