# 已有账号激活管理员权限

后台生成的管理员激活码同时支持新账号注册和已有账号激活。每个码只绑定一个账号；等级来自激活码，客户端不能指定或修改等级。

## 使用方式

1. 有生成权限的管理员在后台「系统设置 → 管理员激活码」选择等级并生成激活码。
2. 用目标账号（例如小 K 的 `xiaok`）登录，打开 `/account`。
3. 在「资料设置 → 管理员权限激活」填写激活码，并确认当前账号密码。
4. 激活成功后立即获得对应权限，点击「进入后台管理」即可使用。普通账号支持激活 lv1–lv3；已有管理员可使用更高等级的码升级。

此操作保留原用户 ID、用户名、头像、内容、积分、关注、粉丝和官方身份。个人中心分别显示社区信誉等级与管理员等级，后台用户列表也显示管理员身份。lv3 仍是普通管理员，不会成为主管理员；现有仅主管理员可访问的功能保持原有权限。

## 接口与一致性

`POST /api/user/activate-admin`，要求当前用户已登录并通过 CSRF 校验：

```json
{
  "activation_code": "后台生成的激活码",
  "password": "当前账号密码"
}
```

目标账号固定为当前已认证用户，不接受代填用户名或用户 ID。系统虚拟账号、未完成注册的普通账号、没有可用密码的账号和主管理员不能通过此入口激活。已有低等级的历史管理员可以升级。

创建/升级管理员记录和消费激活码在同一事务内完成，使用条件更新保证一次性绑定；失败则回滚。激活码记录保留使用人和时间，沿用原审计字段。同一账号重试已经成功使用的码会返回当前权限，不重复创建或降低等级；其他账号不可再次使用。无效、已使用、同级或低等级的码不会被消耗。

权限提升后轮换当前会话，刷新用户与管理员 Cookie，兼容验证旧密码时发生的哈希升级。激活不发放注册或每日奖励。登录密码继续使用原用户密码。

无需数据库迁移，更新后重启 Web 服务并刷新个人中心即可。验证：

```bash
.venv/bin/python manage.py test apps.accounts.test_activation apps.accounts.tests
.venv/bin/python manage.py check
```
