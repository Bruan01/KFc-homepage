# 碎碎念

独立图文信息流 `/murmurs`，与论坛共享账号、头像、上传和站内通知。

## 体验与视觉

桌面端：轻量侧边导航 / 连续时间线 / 日历与记录灵感。
侧栏采用小字号字标与单行日期，弱化装饰；互动区只显示图标与数量，并保留无障碍名称。
发布框、帖子和空状态共用中间栏，使用细分隔线，不使用独立卡片、圆角或阴影。
头像在左，昵称、账号和时间同行，正文和互动按钮沿头像右侧对齐。
手机端：时间线铺满可用宽度，「全部 / 我的」就近切换。
左对齐的中文系统字体，正文 15–16px、1.8 行高；内容宽度约 620px。
沿用站点白天、黑夜、毛玻璃、漫画主题的颜色和材质。
基础色取自现有站点：背景 #f5f5f7、表面 #ffffff、正文 #1d1d1f、
次要文字 #6e6e73、品牌红 #d9232e，交互蓝 #0071e3。
品牌红只突出发布和小型标记；不引入外部字体、图片或营销横幅。

技能检索中的通用落地页布局不适合内容信息流，因此只采用可访问性和轻量交互指导，
布局、字体、颜色继续遵循现有社区。页面的辨识点是「碎碎念。」字标与对话气泡，
其余空间留给真实用户内容；空状态邀请发布，不填充虚构用户或帖子。

## 首版范围

- 公开浏览，按最新顺序分页；支持我的、指定作者和单条分享链接。
- 无标题、无富文本。文字最多 1000 字；图片最多 9 张，每张 5 MB。
- 上传复用 `/api/forum/images`，发布时核验图片所属账号。
- 图片多选/粘贴、上传预览/移除/重试、相册放大和键盘切换。
- 点赞、评论（500 字）、删除本人内容，复用现有点赞/评论通知。
- 评论支持文字、纯图片或图文混合，最多 4 张图片，每张 5 MB；支持选择或粘贴 JPG、PNG、WebP、GIF。
- 评论中的 GIF 表情包保留动画，Emoji 选择器可在光标位置插入常用表情。
- 评论框聚焦后展开图片、Emoji 和发送工具；已有草稿、附件或错误时保持展开。
- 每条评论可点「回复」，输入框显示回复对象并支持取消，图片和 Emoji 同样可用。
- 回复按时间顺序显示，并标记被回复者；原评论被删除或屏蔽后不再展示其内容。
- 回复通知同时发送给碎碎念作者和被回复者，合并相同接收人，不给自己发通知，并遵守屏蔽设置。
- 评论附件支持预览、移除、上传失败重试和放大；发送失败保留文字、图片和请求标识。
- 刷新当前信息流或收起评论区后，评论草稿在本页保留；整页刷新或离开页面后不保留评论草稿。
- 发布和评论支持客户端标识去重；发布间隔 30 秒、评论间隔 5 秒。
- 草稿按账号保存在当前浏览器；请求失败保留内容和已上传图片。
- 屏蔽与取消屏蔽、举报碎碎念或评论、lv2 以上管理员审核和下线。
- 个人主页新增碎碎念页签，站点导航增加入口。

## 数据与运行

新领域应用 `apps.murmurs`，使用 `community_murmur*` 新表；不修改既有论坛内容。
评论附件通过 `community_murmur_comment_images` 关联既有图片，校验归属并保留顺序；
评论接口新增 `images` 数组，旧的纯文字请求保持兼容，举报审核也展示评论附件。
评论请求可增加整数 `reply_to`；响应返回回复对象的账号和简短上下文，不递归嵌套。
时间保存为 ISO 8601 字符串。软删除保留审核记录，管理员删除写入既有治理日志。
发布与评论不奖励积分。举报管理入口 `/murmurs?view=reports`，仅管理员可读取。

更新后先执行 `manage.py backup_database`，再执行 `manage.py migrate --noinput`。
本次包含 `murmurs.0002_comment_images` 和 `murmurs.0003_comment_replies`；迁移后重启 Web 服务并刷新页面。
验证：`manage.py test apps.murmurs`、`manage.py check`、
`manage.py makemigrations --check --dry-run`。
