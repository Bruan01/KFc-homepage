# 心映勋章与社区引导

报告页的「领取并佩戴勋章」在进入视野后柔和提示三次，每次 900ms；同一次打开
不会因反复滚动重复提示。减少动态效果的系统设置使用静态描边。

用户主动点击后，`POST /api/achievements/personality/claim` 附带 `equip: true`，
在原有事务中领取并佩戴当前最新已完成测评的人格勋章。成功跳转到
`/murmurs?welcome=personality`。未传 `equip` 的旧客户端仍只领取并前往勋章馆；
报告完成通知与后台同步不会自动佩戴。重复点击或响应丢失后重试保持幂等，
不会调用模型、消耗 AI 额度或重复发放奖励。

碎碎念使用当前会话返回的已佩戴勋章、本人昵称与头像显示预览，不从 URL 接收
MBTI 或报告答案。只有拥有已佩戴人格勋章的用户能看到这段引导；进入后移除
`welcome` 参数，刷新不再重复弹出。

用户确认「用这句话打个招呼」后，在空白发布框内生成可修改的开场白：

> 新鲜出炉的 INFP，来社区报个到。

类型来自本人实际佩戴的勋章。若已有文字、图片或视频草稿，保留原内容和频道，
按钮改为「继续编辑我的草稿」。确认后聚焦输入框，提示用户点击发布按钮，
不会自动发帖；取消引导也不会新增草稿。正常发布成功后移除提示。

验证：

```bash
.venv/bin/python manage.py test apps.gamification.test_personality_badges apps.gamification.test_showcase
node scripts/test_personality_community_guide.cjs
```

浏览器用例覆盖桌面、手机尺寸、减少动态效果、原草稿、取消、伪造引导参数、
失败重试和手动发布。无数据库迁移；发布时清除旧 HTML 的 CDN 缓存。

## 首条碎碎念积分与显影入口

每个真实账号首次发布有效碎碎念，默认获得 10 K 积分。后台「积分管理」可调整
首条碎碎念奖励，设为 0 关闭；配置键为 `points.murmurs.first_post_reward`。
判断首次时计入历史与已删除的记录，不按注册日期设额外门槛；系统虚拟账号和
积分冻结账号不获得奖励。已有帖子不追溯补发，评论不属于首条碎碎念。

奖励使用现有积分账本，事件 `murmur_first_post`，每账号唯一幂等键，与发帖在
同一事务内完成。首次写入前预留 SQLite 写锁；失败回滚，重复提交、删除重发
不会重复加分。响应丢失后重试同一发布请求，可以重新取得原到账回执。

`GET /api/murmurs/session` 增加 `first_post_reward` 资格与当前配置；发布接口
增加同名到账回执，其余返回字段保持。只向具备资格的账号提示首帖奖励；
发布成功后展示实际到账金额及「显影 · AI 生图」入口，不自动消耗积分或生成图片。
示例图片来自本次提供的创作参考，三张原图只在奖励弹窗中按需加载，文案注明效果
与模型及描述有关。默认生图费用按后台配置展示，不承诺任意模型均可兑换一次。


## 注册到账提示和心映费用

注册接口增加 `registration_reward` 回执，包括实际注册奖励、当前心映/显影费用和
首帖奖励资格。注册页成功后展示到账与用途弹窗，默认 20 K；按钮保留原先 `next`
目的地，用户也可选择心映、显影或碎碎念。不自动扣费、不自动生成图片。

心映新测评默认 10 K，后台「积分管理」可调整（0 为免费），配置键
`points.personality.assessment_cost`。开始页展示费用和余额，需确认 AI 与扣费后
才创建新测评。新测评创建与积分扣除在同一事务；使用客户端请求键幂等，网络失败
或重复点击重试不会重复扣费。客户端在当前账号的 sessionStorage 保留未完成请求键。
继续旧测评、答题、查看报告和失败重试均不重复扣费。删除测评不退还开始费用；
已删除测评的原请求重试返回 410，不重新创建或扣费。新建另一份测评需再次付费。
未确认当前费用的旧客户端返回提示，不静默扣款。余额不足、冻结或服务未就绪不会扣费。

验证新增：`apps.personality.test_billing`、`apps.accounts.test_registration_reward`、
`node scripts/test_points_onboarding.cjs`，覆盖实际回执金额、扣费幂等、事务回滚、
余额/费用变化，以及手机/桌面提示、明确费用和失败后刷新重试。
