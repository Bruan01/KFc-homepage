# 产品详情页代码包下载区设计

## 目标

将产品详情页现有的代码包卡片改为参考 Oracle 下载页的标签页表格布局，同时保留现有登录、下载资格与重复下载审批逻辑。

## 页面结构

- 代码包区域放在“更新日志”之后、“下载校验信息”之前。
- 顶部展示实际存在的操作系统标签页，优先顺序为 Linux、macOS、Windows，其余平台随后展示。
- 标签页下方使用三列表格：
  1. 产品/文件说明
  2. 文件大小
  3. 下载
- 文件说明由架构、包类型和文件名构成。
- 下载列展示文件名链接与 SHA256 复制入口。
- 移动端将表头隐藏，每个文件行改为带字段标签的纵向布局。

## 行为

- 默认选中第一个存在的操作系统标签。
- 切换标签仅过滤当前 API 已返回的包，不重新请求接口。
- 管理员始终可以下载。
- 普通用户仅在拥有下载资格时显示有效下载链接；否则显示登录、申请中或无资格提示。
- 兼容未配置 `product_packages` 的旧产品，旧的主下载按钮及校验区域保持不变。

## Markdown

详情、更新日志与公告当前已经通过页面内置的安全 Markdown 渲染器输出，支持标题、段落、强调、删除线、链接、行内代码、代码块、列表、引用和表格。本次不引入第三方依赖，只修正渲染细节并进行回归验证。

## 验收标准

- 多平台包可按标签切换。
- 表格列、分隔线、留白和激活标签接近参考图。
- 文件大小使用自适应单位。
- 下载权限不会被新表格绕过。
- SHA256 可复制并有反馈。
- 桌面和移动端均无横向页面溢出。
- Markdown 内容继续正确、安全地渲染。
