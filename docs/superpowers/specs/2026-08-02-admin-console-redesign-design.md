# KFlow 后台企业级控制台重构设计

## 目标

将现有后台从“功能堆叠的长页面”升级为企业级运营控制台，提升三个核心指标：定位功能的速度、读取业务状态的速度、执行高风险操作的确定性。保留现有 Django API、权限判断、表单字段、DOM ID 和业务流程，不引入新的前端框架或构建链。

## 视觉方向

采用控制面（Control Plane）风格：深石墨侧栏承载导航，浅灰工作区承载业务卡片，KFlow 橙色只用于品牌、当前状态和主操作。整体减少渐变、超大标题和过度圆角，使用 10–16px 的克制圆角、清晰边界、紧凑表格和一致的状态色。

后台顶部固定为“品牌 + 环境/身份 + 高频操作”，侧栏固定为“页面导航 / 业务域 / 系统设置”，内容区统一使用页面标题、状态摘要、工具条、数据表或表单四段结构。当前页面的锚点导航继续保留，并增强当前项、滚动偏移和折叠状态。

## 页面改造

1. `admin.html`：建立运营控制台壳层；概览区改成带状态摘要和快捷动作的工作台头部；产品、审批、积分、商城、股市、显影配置和用户模块统一面板、表格、表单、按钮及危险操作样式。
2. `admin-bigscreen.html`：复用同一套壳层、色彩、导航、状态卡片和筛选控件，保留大屏的趋势图、漏斗图和业务记录能力。
3. `admin-login.html` / `admin-register.html`：使用同一品牌与认证视觉，提供明确的环境/权限提示和更强的表单可读性。
4. `styles.css`：在后台作用域内建立最终覆盖层，收拢历史样式冲突；不修改官网、商城和用户侧页面的视觉变量。

## 交互与实用性

- 高频动作（产品编辑、收件箱、退出、刷新）固定在顶部，主按钮只有一个视觉主层级。
- 侧栏支持折叠，状态保存在本地；移动端改为顶部可滚动业务导航，内容不被固定侧栏遮挡。
- 表格保持横向滚动而不是压缩字段，表头、搜索、筛选和分页保持相同高度。
- 成功、警告、错误、权限不足使用统一状态徽章；危险操作使用红色二次确认语义。
- 表单字段按业务分组，输入控件聚焦态明显，禁用态和保存反馈可识别。
- 保留现有 `id` 和事件绑定，所有新装饰元素不承担业务状态，避免破坏脚本。
